# Sales Dashboard – Google Sheet Connected

This dashboard reads live data from Google Sheets.

Sheet tab:
`Sheet1`

Before deploying:
1. In Google Sheets, Share → General access → Anyone with the link → Viewer.
2. Upload `index.html`, `style.css`, and `script.js` to the same GitHub repository.
3. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → / (root).

No CSV needs to be uploaded to GitHub.
